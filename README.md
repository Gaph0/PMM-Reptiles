# Project Momo Reptiles

Reptile momos for Project Momo: two mountain factions (neutral Dragonia and the
hostile lewdist Scalebound Broods), the reptilian gene (egg-laying, scale
shedding, sharp hide, warmth-loving), and the lamia tail-grapple gene.

See `PLAN.md` for the full design. Requires Harmony, Biotech, Ideology,
Vanilla Expanded Framework, and Project Momo.

Build with `./build.sh` (needs Project Momo built first).
